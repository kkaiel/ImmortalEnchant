# ImmortalEnchant — 불멸 인챈트 (개발 초안)

대상 서버: Paper 26.3 / Java 25

## 포함된 초안 기능
- 불멸 테마 장비 8종 테스트용 지급 명령어
- PDC 기반 커스텀 장비 식별 및 옵션/강화 단계 저장
- 최초 옵션 생성 GUI 및 합의된 광물 블록 9종 + 경험치 1레벨 비용 확인/차감
- 장비별 고정 긍정 옵션 2개 + 부정 옵션 1개 + 네 번째 무작위 옵션 생성
- 약함/보통/강함 티어 추첨
- 강화 GUI, 5회 시도, 시도별 확률/비용, 실패 시 옵션 유지 및 단계 상승
- 무한 내구도, 기본 장비 능력치, 한국어 이름/설명
- 손에 든 발광 옵션 장비의 발광 효과 갱신
- 설정 파일 및 `/immortal reload`

## 명령어
- `/immortal give <sword|axe|pickaxe|crossbow|helmet|chestplate|leggings|boots>` — 테스트 장비 지급 (OP)
- `/immortal enchant` — 손에 든 장비의 최초 옵션 생성 GUI
- `/immortal anvil` — 손에 든 장비 강화 GUI
- `/immortal reload` — 설정 다시 불러오기 (OP)

## 빌드
JDK 25와 Gradle이 필요합니다.

```bash
gradle build
```

생성물: `build/libs/ImmortalEnchant-1.0.0.jar`

## 현재 개발 상태 / 주의
이 파일은 첫 개발 초안이며, 운영 서버에 바로 투입할 완성본으로 검증된 상태가 아닙니다. 이 실행 환경에는 Java 21만 설치되어 있고 외부 저장소 접속도 불가능해 Paper 26.3 API 대상으로 컴파일/서버 테스트를 수행하지 못했습니다.

또한 옵션의 실제 전투·장비 효과 중 현재 초안에서 처리하는 것은 근접 공격력 추가/감소, 블록 경험치 보너스, 발광입니다. 공격 속도 옵션의 실제 적용, 채굴 속도, 석궁 투사체 피해, 최대 체력/방어력/방어 강도 옵션의 실제 속성 반영, 옵션 재적용/해제의 안전성은 다음 구현 단계에서 완성하고 서버 테스트해야 합니다. 현재 GUI의 옵션 표시는 저장된 옵션을 보여주는 것이며, 미구현 효과까지 실제 적용된다고 간주하면 안 됩니다.

테스트 장비는 별도 제작 플러그인 연동 전 임시 지급용입니다. 이후 실제 장비 플러그인의 PDC 식별자에 맞춰 연동해야 합니다.
